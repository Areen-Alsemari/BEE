## Fixed BEE (F2) (fixed (member 3))

- Stimulus weights: scarcity 0.5, contention 0.3, unmet 0.2
- placement_scarcity: 1 minus min(remaining feasible placements / number of visibility periods of the request, 1)
- resource_contention: static: the request's static_resource_contention from the processed data, min-max normalised and clipped to [0, 1] (normalisation: min and max of static_resource_contention over the training weeks of the run (per fold in the cross-week runs))
- mission_unmet_ratio: 1 minus (seconds allocated so far to the request's mission / seconds requested by that mission this week); not clipped before use
- Stimulus: scarcity_weight * scarcity + contention_weight * contention + unmet_demand_weight * unmet (no clip in the formula; the whole observation is clipped to [0, 1])
- Threshold: fixed at 0.5
- Activation: s^k / (s^k + threshold^k) (no epsilon, no clip), k = 2.0

## Adaptive BEE (A6) (adaptive (member 4))

- Stimulus weights: scarcity 0.4, contention 0.4, unmet 0.2
- placement_scarcity: 1 minus (current number of feasible placement candidates / number of candidates when the request was first seen this episode), clipped to [0, 1]
- resource_contention: dynamic: number of other currently valid requests that share at least one candidate antenna, divided by (number of valid requests - 1), capped at 1 (normalisation: none beyond the division by (valid requests - 1); recomputed at every step)
- mission_unmet_ratio: 1 minus (seconds allocated so far to the request's mission / seconds requested by that mission this week), clipped to [0, 1]
- contention_increase: max(current contention - contention when the request was first seen this episode, 0)
- relative_unmet_pressure: max(mission unmet ratio - mean unmet ratio over missions with requested time, 0)
- Stimulus: clip(w_scarcity * scarcity + w_contention * contention + w_unmet * unmet, 0, 1)
- Threshold: clip(base - scarcity_strength*scarcity - contention_strength*contention_increase - unmet_strength*relative_unmet_pressure, minimum, maximum) when adaptation is enabled, else base; base 0.5, strengths scarcity 0.2, contention 0.15, unmet 0.15, clip [0.1, 0.9]
- Gate: selective_mode True; limits scarcity >= 0.3, contention increase >= 0.1, relative unmet >= 0.1; needs 2 indicators
- Activation: clip(s^k / (s^k + threshold^k + 1e-8), 0, 1), k = 2.0

## Differences between the streams

Fixed BEE (F2) and adaptive BEE differ in stimulus weights, in the contention definition (static min-max over training weeks vs dynamic competitors / valid actions), in the scarcity definition and in the activation formula details (no 1e-8 term and no clipping in F2). Adaptive minus fixed BEE is therefore not an isolated effect of the threshold rule (see N4).
